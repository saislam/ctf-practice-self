# ctf-practice-self

A Capture The Flag (CTF) practice repository for learning cybersecurity and forensics skills.

## Available Challenges

### Challenge 1: Hidden in Plain Sight
**Difficulty:** Easy  
**Points:** 100  
**Description:** Find the flag hidden in this repository's git history.

See [CHALLENGE.md](CHALLENGE.md) for full details.

## How to Use

1. Clone this repository
2. Read the challenge description in `CHALLENGE.md`
3. Try to solve the challenge on your own
4. If you get stuck, check `SOLUTION.md` for the complete solution

## Learning Objectives

- Understanding git history and forensics
- Learning to investigate repositories for hidden information
- Practicing common CTF techniques

## Tools You Might Need

- `git` - for examining repository history
- Basic command-line skills
- A text editor

Good luck and happy hacking! 🚩
