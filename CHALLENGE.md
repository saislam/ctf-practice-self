# CTF Challenge: Hidden in Plain Sight

## Description
Welcome to your first CTF challenge! Your mission is to find the hidden flag.

## Objective
Find the flag hidden somewhere in this repository. The flag format is: `FLAG{...}`

## Hints
1. Not everything is as it seems
2. Check the git history carefully
3. Sometimes important information is hidden in commits

Easy
